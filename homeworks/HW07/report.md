## 5. Analysis

### 5.1 Сравнение алгоритмов (важные наблюдения)

KMeans "ломается" на ds3 из-за кластеров разной плотности и нелинейных форм. Алгоритм пытается разделить пространство на равные по размеру кластеры, что не соответствует реальной структуре данных.
DBSCAN выигрывает на ds3 благодаря способности находить кластеры произвольной формы и разной плотности, а также обрабатывать выбросы.
Сильнее всего влияло на результат:
Масштабирование - критически важно для всех distance-based методов
Структура кластеров (плотность, форма) - определяющий фактор для выбора алгоритма
Наличие шумовых признаков - снижало качество, но после препроцессинга влияние уменьшилось
Подбор гиперпараметров - автоматический подбор eps для DBSCAN значительно улучшил результаты

### 5.2 Устойчивость (обязательно для одного датасета)

Для ds1 проводилась проверка устойчивости KMeans через 5 запусков с разными random_state (0-4). Рассчитывался adjusted_rand_score (ARI) между первым запуском и остальными.

Результаты: ARI составил [0.998, 0.997, 0.999, 0.998], что указывает на высокую устойчивость результата.

Вывод: Кластеризация для ds1 устойчива, так как данные имеют четкую структуру из двух компактных кластеров, которые легко обнаруживаются алгоритмом независимо от инициализации.

### 5.3 Интерпретация кластеров

Для интерпретации кластеров анализировались распределения признаков внутри каждого кластера:

Для ds1: выявлены два кластера с противоположными значениями по оси x1 на PCA. Первый кластер имеет положительные средние значения по большинству признаков, второй - отрицательные.
Для ds2: кластеры разделяются по оси x1, с четкой границей около 0.5.
Для ds3: три кластера с разной плотностью, центральный кластер плотнее периферийных.
Вывод: кластеры в ds1 и ds2 имеют четкую интерпретацию по ключевым признакам, в ds3 кластеры лучше интерпретируются через их расположение в пространстве PCA.

## 6. Conclusion

Разные алгоритмы кластеризации лучше подходят для разных типов данных - выбор должен основываться на структуре данных.
Автоматический подбор гиперпараметров (особенно для DBSCAN) критически важен для получения хороших результатов.
Препроцессинг (масштабирование) обязателен для distance-based методов и значительно влияет на результат.
Внутренние метрики качества (особенно silhouette) полезны, но не всегда отражают визуальное качество кластеризации.
PCA визуализация необходима для интерпретации и проверки результатов кластеризации.
Проверка устойчивости результатов важна для подтверждения надежности кластеризации.
Кластеры с разной плотностью и нелинейными формами требуют алгоритмов, не предполагающих сферическую форму кластеров.
Шум и выбросы могут значительно снижать качество кластеризации, поэтому их обработка важна на этапе препроцессинга.
